# 苏州旅行指南

**简介**：人间天堂苏州，古典园林冠绝天下，小桥流水人家，吴侬软语温婉。

- 省份：江苏
- 最佳旅行季节：3-5月、9-11月
- 特色标签：园林、古镇、文艺、江南水乡
- 必尝美食：松鼠桂鱼、苏式汤面、大闸蟹
- 关键词：古典园林、周庄、平江路

## 旅行亮点
- 拙政园：中国园林之首，借景北寺塔，四季皆有画意
- 平江路历史街区：小桥流水人家，评弹声里的宋代古巷
- 虎丘：吴中第一名胜，云岩寺塔比萨斜塔东方版
- 周庄古镇：中国第一水乡，双桥与沈厅摇橹船

## 住宿建议
- 苏州洲际酒店（约700元/晚，评分4.7）：金鸡湖畔，湖景摩登
- 苏州平江路书香府邸酒店（约450元/晚，评分4.6）：平江路深处的苏式园林宅院

## 美食推荐
- 松鼠桂鱼
- 苏式汤面
- 大闸蟹

## 小贴士
- 苏州海拔与气候：人间天堂苏州，古典园林冠绝天下，小桥流水人家，吴侬软语温婉。
- 旺季出行请提前订票订房，热门景点建议错峰游览。
