# 拉萨旅行指南

**简介**：日光城拉萨，布达拉宫巍峨耸立，八廓街转经人流，离天空最近的圣城。

- 省份：西藏
- 最佳旅行季节：5-10月
- 特色标签：高原、人文、宗教、摄影
- 必尝美食：酥油茶、甜茶、牦牛肉
- 关键词：布达拉宫、大昭寺、高原圣城

## 旅行亮点
- 布达拉宫：世界上海拔最高的宫殿，需提前预约并遵朝圣路线
- 大昭寺：藏传佛教中心，释迦牟尼十二岁等身像
- 八廓街：转经道环形老街，藏式手作与甜茶馆
- 色拉寺：辩经圣地，午后激烈辩经场面不容错过

## 住宿建议
- 拉萨瑞吉度假酒店（约1100元/晚，评分4.8）：藏式庭院度假村，布宫景致
- 拉萨香格里拉大酒店（约800元/晚，评分4.7）：布达拉宫远景，全屋供氧

## 美食推荐
- 酥油茶
- 甜茶
- 牦牛肉

## 小贴士
- 拉萨海拔与气候：日光城拉萨，布达拉宫巍峨耸立，八廓街转经人流，离天空最近的圣城。
- 旺季出行请提前订票订房，热门景点建议错峰游览。
