# 张家界旅行指南

**简介**：扩大的盆景缩小的仙境，三千奇峰拔地而起，《阿凡达》悬浮山原型地。

- 省份：湖南
- 最佳旅行季节：4-6月、9-11月
- 特色标签：自然风光、世界遗产、登山、摄影
- 必尝美食：三下锅、岩耳炖土鸡、土家腊肉
- 关键词：武陵源、天门山、玻璃栈道

## 旅行亮点
- 武陵源·张家界国家森林公园：世界自然遗产，袁家界乾坤柱与金鞭溪，建议2天
- 天门山国家森林公园：999级天梯与玻璃栈道，天门洞开天下奇
- 张家界大峡谷玻璃桥：世界最长玻璃桥，云天渡上漫步峡谷之上
- 黄龙洞：定海神针石笋，洞内暗河乘船，恒温避暑

## 住宿建议
- 张家界武陵源铂尔曼酒店（约700元/晚，评分4.7）：武陵源标志门旁，峰林景观
- 张家界华天大酒店（约380元/晚，评分4.5）：市区天门山索道站附近

## 美食推荐
- 三下锅
- 岩耳炖土鸡
- 土家腊肉

## 小贴士
- 张家界海拔与气候：扩大的盆景缩小的仙境，三千奇峰拔地而起，《阿凡达》悬浮山原型地。
- 旺季出行请提前订票订房，热门景点建议错峰游览。
