# 杭州旅行指南

**简介**：人间天堂杭州，西湖十景如诗如画，龙井茶香氤氲，江南韵味十足。

- 省份：浙江
- 最佳旅行季节：3-5月、9-11月
- 特色标签：自然风光、人文、茶文化、情侣
- 必尝美食：西湖醋鱼、东坡肉、龙井虾仁
- 关键词：西湖、龙井茶、江南水乡

## 旅行亮点
- 西湖：十景如画，苏堤春晓、断桥残雪，四季皆景
- 灵隐寺：千年古刹，飞来峰造像精美，香火鼎盛
- 西溪湿地：城市湿地公园，摇橹船穿行芦苇荡，野趣盎然
- 千岛湖：天下第一秀水，1078座岛屿星罗棋布

## 住宿建议
- 杭州西子湖四季酒店（约3200元/晚，评分4.9）：西湖边江南园林式酒店
- 杭州西湖国宾馆（约1500元/晚，评分4.8）：刘庄园林，湖景套房

## 美食推荐
- 西湖醋鱼
- 东坡肉
- 龙井虾仁
