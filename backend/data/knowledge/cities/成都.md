# 成都旅行指南

**简介**：天府之国成都，熊猫基地必打卡，火锅美食遍地，城市节奏悠闲。

- 省份：四川
- 最佳旅行季节：3-6月、9-11月
- 特色标签：美食、熊猫、休闲、人文
- 必尝美食：火锅、串串香、担担面、兔头
- 关键词：大熊猫、火锅、天府文化

## 旅行亮点
- 大熊猫繁育研究基地：近距离围观滚滚大熊猫，幼年熊猫最活泼
- 宽窄巷子：清代古街改造的成都名片，宽巷窄巷井巷各有风情
- 都江堰：世界文化遗产，两千年水利工程至今泽被天府
- 青城山：道教名山，青城天下幽，前山道观林立

## 住宿建议
- 成都博舍酒店（约1800元/晚，评分4.9）：太古里核心，设计师酒店
- 成都明宇尚雅饭店（约420元/晚，评分4.5）：春熙路商圈，交通便利

## 美食推荐
- 火锅
- 串串香
- 担担面
- 兔头

## 小贴士
- 成都海拔与气候：天府之国成都，熊猫基地必打卡，火锅美食遍地，城市节奏悠闲。
- 旺季出行请提前订票订房，热门景点建议错峰游览。
