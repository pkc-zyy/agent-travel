# 丽江旅行指南

**简介**：丽江古城世界文化遗产，玉龙雪山巍峨壮丽，纳西风情独特，是浪漫旅行的代名词。

- 省份：云南
- 最佳旅行季节：四季皆宜
- 特色标签：古镇、雪山、浪漫、摄影
- 必尝美食：腊排骨、鸡豆凉粉、丽江粑粑
- 关键词：古城、玉龙雪山、纳西文化

## 旅行亮点
- 丽江古城：世界文化遗产，四方街流水人家，夜生活与酒吧文化热闹
- 玉龙雪山：纳西神山，冰川公园海拔4680米，蓝月谷水色湛蓝
- 蓝月谷：玉龙雪山脚下，湖水因矿物呈现梦幻蓝色
- 束河古镇：茶马古道重镇，比大研古城更安静，青龙桥古韵犹存

## 住宿建议
- 丽江古城安隅酒店（约650元/晚，评分4.7）：古城中心纳西庭院，私密安静
- 丽江金茂璞修雪山酒店（约1500元/晚，评分4.9）：雪山脚下，推窗见玉龙
