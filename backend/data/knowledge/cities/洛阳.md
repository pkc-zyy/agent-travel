# 洛阳旅行指南

**简介**：十三朝古都洛阳，龙门石窟千年庄严，四月牡丹倾城，河图洛书之源。

- 省份：河南
- 最佳旅行季节：4-5月（牡丹）、9-11月
- 特色标签：历史人文、古迹、赏花
- 必尝美食：洛阳水席、牛肉汤、浆面条
- 关键词：龙门石窟、牡丹、白马寺

## 旅行亮点
- 龙门石窟：世界文化遗产，卢舍那大佛微笑千年
- 白马寺：中国第一古刹，佛教传入中国第一寺
- 洛阳博物馆：河洛文明珍宝，唐三彩与曹魏白玉杯
- 丽景门·老城十字街：中原第一门，夜市水席与不翻汤

## 住宿建议
- 洛阳东山宾馆（约550元/晚，评分4.7）：龙门石窟旁，山水园林
- 洛阳华阳广场国际大饭店（约420元/晚，评分4.6）：涧西区，牡丹广场商圈

## 美食推荐
- 洛阳水席
- 牛肉汤
- 浆面条

## 小贴士
- 洛阳海拔与气候：十三朝古都洛阳，龙门石窟千年庄严，四月牡丹倾城，河图洛书之源。
